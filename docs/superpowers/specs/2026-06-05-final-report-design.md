## 4. 前處理（`scripts/prepare_edu.py`，pandas）

每一步同時是 Word「二、資料來源與前處理」的素材：

1. Tab 分隔 → 標準逗號 CSV，UTF-8 with BOM。
2. **欄位重新命名**為中文（user_sn→使用者編號…），附完整對照表。
3. **缺失值處理**：成績缺漏列保留於行為分析、於成績相關分析排除並註記
   （國 120、數 45、英 112 筆）。
4. 時間標準化：timestamp 解析；衍生 年/月/週/星期/時段；ISO8601 時長
   （PT1M35S）→ 秒；Unix ms → datetime。
5. `binary_res` 以 `@XX@` 拆分 → 題數、答對數。
6. 彙整合併：join user_data、按使用者/影片瀏覽/題項聚合。

### 產出（`data/edu/*.csv`，皆入庫供 Power BI 連結）

| 檔案 | 粒度 | 主要欄位 | 對應主題 |
|------|------|----------|---------|
| `edu_activity.csv` | 事件（~9.5 萬列） | 使用者、平臺(dp001–004)、行為類型、時間戳＋年/月/週/星期/時段、學校、年級 | 1 |
| `edu_users.csv` | 使用者（313） | 學校、年級、班級、國數英成績、練習次數/平均正確率/總秒數、影片瀏覽次數/總時長/平均完成率、倒轉次數、筆記次數、單字與數學遊戲量、dp002 測驗量、dp004 活動量、參與度四分位 | 2 |
| `edu_video.csv` | 影片瀏覽（~4,567） | 使用者、科目、影片名、影片長度、finish_rate、本次瀏覽之 暫停/倒轉/快轉/筆記/檢核點 事件數（自 review_plus 聚合） | 3 |
| `edu_difficulty.csv` | 題項 union | 類型(能力指標/英文單字/數學單元)、名稱、科目、嘗試次數、正確率、累積錯誤次數 | 4 |

腳本內建 asserts：各表列數、鍵唯一性、成績缺失數=120/45/112、時長非負、
binary_res 解析後題數一致。

## 5. Power BI（4 個語意模型 → 4 份報表，瀏覽器製作）

模型一律「取得資料 → CSV → 連結」＋ Pages URL（匿名）。僅用服務內建視覺效果。

- **報表1 學習平臺使用概況**（edu_activity）：卡片（使用者數/學校數/總活動量）、
  年級×人數直條、學校圓環、各平臺活動量直條、週趨勢折線（開學→期末）、
  星期×時段矩陣熱度、平臺篩選器。
- **報表2 學習行為與成績關聯**（edu_users，主打）：散佈圖（練習正確率×數學成績、
  影片完成率×英文成績；年級圖例＋趨勢線）、參與度四分位×平均成績群組直條、
  行為指標卡片、學校/年級篩選器。
- **報表3 影片學習行為解析**（edu_video）：完成率分布、科目別完成率、
  行為事件組成堆疊、最常被倒轉影片 Top 10 橫條（教材難點）、科目篩選器。
- **報表4 科目與能力難點**（edu_difficulty）：各科正確率直條、最弱能力指標
  Top 10、最難英文單字（累積錯誤）、最難數學單元、樹狀圖（科目→指標）、
  類型篩選器。

發佈至 Web 可用 → 網站嵌入；被封 → 截圖＋連結（Word 與影片本來就用截圖/錄影，
不受影響）。

## 6. Word 期末報告（`scripts/build_report_docx.py`，python-docx 生成 .docx）

公告指定 Word 檔。結構（目標 12–15 頁）：

1. **封面**：題目（暫定「運用 Power BI 分析國小學習平臺行為與學業成績」）、
   姓名/學號/系級（**生成時向使用者收集**）、指導教授、日期、影片連結。
2. **一、分析主題**：4 個研究問題（每主題一問）。
3. **二、資料來源與前處理**：出處與授權聲明、11 檔案清單表（筆數/欄數）、
   欄位重命名對照、缺失值統計與處理、Python 程式片段、處理前後截圖。
4. **三、資料分析與視覺化**：4 主題 ×（儀表板截圖＋具體發現敘述，採老師例示
   句式「發現○○最多、○○顯著增加」）。
5. **四、結論與建議**（約一頁）＋**影片說明與連結**。

排版微調由使用者在 Word 中完成（內容與圖表由腳本產生）。

## 9. 風險與備援

| 風險 | 備援 |
|------|------|
| 發佈至 Web 被 NCUE 封鎖 | 截圖＋連結模式；Word/影片不受影響 |
| 教育資料授權疑慮 | 原始資料不入庫；僅公開彙總表；註明出處與教學用途 |
| python-docx 排版生硬 | 使用者於 Word 微調樣式 |
| 成績缺失值多（英 112/313） | 散佈圖樣本仍約 200 人；報告中明載排除規則 |
| 瀏覽器自動化卡住 | 該步驟轉手動指引 |
