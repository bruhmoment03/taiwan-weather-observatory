## 2. 報表2　學習行為與成績關聯（約 90 秒，重點段落）

🖱️ 開啟 報表2 → 滑鼠在左邊散佈圖的點上慢慢掃過 → 指右邊散佈圖。

「第二張是整份報告的主打：學習行為跟成績到底有沒有關係？
每一個點是一位學生，顏色代表年級。我們把行為指標跟國數英成績做相關分析，
發現最強的訊號是『影片瀏覽次數』跟英語成績——相關係數 0.336；
跟國文成績也有 0.288。相對地，練習題寫得多不多、正確率高不高，
跟成績幾乎沒有相關。也就是說，在這份資料裡，
『影音學習的投入』比『刷題量』更能反映學業表現。」

🖱️ 指向 參與度×成績 群組直條圖，從 Q1 比到 Q4。

「再把學生依總活動量分成四組。最高參與的 Q4 組，三科平均全面領先：
國文 83.5 分、英語 81.3 分，比中低參與組高出 6 到 10 分。
但要注意，數學的相關普遍偏弱，代表數學成績可能更取決於課堂教學等平臺外的因素。
另外這個分析已經排除了成績缺漏的學生，相關不代表因果，這是描述性的證據。」

## 3. 報表3　影片學習行為解析（約 60–90 秒）

🖱️ 開啟 報表3 → 指 各科平均完成率 橫條圖的頭尾 → 再指 行為組成 堆疊圖。

「第三張看學生怎麼看影片。整學期 4,567 次影片瀏覽，平均完成率 71%。
科目差異很明顯：國語文和英語的影片完成率都超過 85%，數學最低、只有 66%——
發現數學影片最難讓學生堅持看完。行為組成上，11 萬 8 千筆操作事件裡，
倒轉有 2,210 次、快轉只有 771 次，倒轉是快轉的 2.9 倍——
學生回頭重看的次數遠多於跳著看。」

🖱️ 指向 最常被倒轉影片 Top 10 橫條圖，停在第一名。

「最有意思的是這張：被倒轉最多次的前十名影片，全部都是資訊教育的
Scratch 遊戲設計教材，第一名『自動與手動開始的遊戲場景』被倒轉了 285 次。
高倒轉影片其實就是一份現成的教材難點清單，老師可以針對這些單元放慢節奏。」

## 4. 報表4　科目與能力難點（約 60–90 秒）

🖱️ 開啟 報表4 → 指 各科正確率 直條 → 指 最弱能力指標 橫條。

「第四張找難點。以能力指標的答題正確率來看，國語文加權正確率 65.6% 反而是最低的——
對照前面國語文影片完成率最高，發現『看完影片』不等於『理解內容』。
最弱的指標包括資訊教育的『簡報物件動畫設計』，正確率只有 30%。」

🖱️ 指向 最難英文單字 橫條圖（橘色），逐一掃過 whether、which、how。

「英文單字的難點高度集中：錯誤次數前十名裡，有七個是 WH 開頭的疑問詞——
whether、which、how、where、whose、why、when，其中 which 的正確率只有 31.2%。
發現 WH 疑問詞是這群國小學生英語學習的系統性弱點。
數學方面，『等量公理』正確率 25.4%、『分數小數混合四則運算』30%，
都是抽象運算概念；基礎單元像 10 以內加減都有九成以上——難度斷層出現在抽象化的階段。」
