製作說明（含 DAX）

矩陣：列=測站、行=item_display、值=濃度平均；臭氧欄位以 DAX 量值配條件格式化圖示 （<30 綠、<40 黃、其餘紅）。

臭氧等級 =
VAR CurrentItem = SELECTEDVALUE(aqx_p_08[itemname])
VAR O3 = AVERAGE(aqx_p_08[concentration])
RETURN IF(CurrentItem = "臭氧",
  SWITCH(TRUE(), O3 < 30, 1, O3 < 40, 2, 3), BLANK())

欄位顯示名稱由計算資料行 item_display（SWITCH 對照 15 種測項之英文縮寫）產生。
